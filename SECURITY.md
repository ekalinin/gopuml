# Security policy

## Supported versions

Security fixes go into the latest release, currently v0.1.0.

## Reporting a vulnerability

Report vulnerabilities privately on GitHub:
[report a vulnerability](https://github.com/ekalinin/gopuml/security/advisories/new)
(the Security tab of the repository). Do not open a public issue for them.

Include the version (`plantuml --version`), the way gopuml is used (command
line, Go library, HTTP server or WebAssembly module), and the diagram source or
the request that shows the problem.
